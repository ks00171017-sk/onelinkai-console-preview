钱包与账单衔接建议

方案建议，未修改demo。扣款记录不能替代账单；共享钱包需保护押金。充值可在交付前或交付后发生。

下载PNG
查看可编辑的流程源码
flowchart TD
  cash[核实对公到账] --> credit[服务费充值现有钱包]
  credit --> available[可用余额须排除押金]
  delivery[运营发布整单交付] --> bill[自交付日生成服务账单]
  bill --> debit[运营从账单发起扣款]
  available --> debit
  debit --> result{本次扣款成功}
  result -->|成功| linked[关联订单与账单编号]
  linked --> settled[更新账单已结算金额]
  result -->|未成功或余额不足| follow[保留未结金额并催款]

交付即起算 · 无租户确认 · 线下运维仅接收部署需求 · 押金不作服务费扣用
