# GPU Atlas · GPU 选型图谱

直接用浏览器打开 `index.html`，无需构建或安装依赖。图片引用外部厂商/供应商资源，需要联网。

- 13 款 GPU：外观图、显存、CUDA 核心、带宽、功耗、模型适配、部署与价格参考。
- 支持搜索、类别及显存筛选、排序、CSV 导出、命令复制与打印。
- 资料查询日期：2026-11-12；网页整理日期：2026-11-13。价格为快照，不是实时行情；模型容量为估算，不是实测。
- 页面来源链接保留原资料；无法核实的规格和价格明确标注。

## 维护

修改 build.py 中的数据与模板后运行：

```sh
python3 build.py
node verify.cjs
```

生成 `index.html` 与 `data.json`。`verify.cjs` 检查搜索、筛选、排序、空结果和重置。
